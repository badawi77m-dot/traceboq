# TraceBOQ

AI-powered construction estimating platform that turns drawings into a **traceable Bill of Quantities**.

**Upload your drawings. Get a traceable BOQ in minutes.**

## Product

Engineers, contractors, quantity surveyors, and construction companies upload architectural, structural, electrical, and mechanical drawings. The workspace produces a structured BOQ where every quantity is linked to:

- source drawing and page
- measurement / evidence
- calculation
- confidence level

Reviewers edit quantities, then export Excel or PDF.

Roadmap: local construction prices so the path is Drawings → Takeoff → BOQ → Pricing → Project estimate.
